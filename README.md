# R2Beat 2013 (móvil)

Descargas del juego R2Beat 2013 para Android.

## Descargar

Entra en **[Releases](../../releases/latest)** y descarga el archivo `.apk` de la última versión.

## Instalar

1. Abre el `.apk` desde el móvil.
2. Si Android lo pide, permite **instalar aplicaciones de origen desconocido** para tu navegador o gestor de archivos.
3. Abre **R2Beat**, escribe tu nombre de usuario y pulsa **ENTRAR**.

## Primera vez: canciones, ropa y caras

El APK trae lo básico. Las canciones, la ropa y las caras de la tienda se descargan desde el propio juego:

1. En la pantalla de inicio verás «Hay … canciones por descargar».
2. Pulsa **ACTUALIZAR**. Son unos **3,4 GB**: se recomienda **Wi-Fi**.
3. Puedes **CANCELAR** cuando quieras: la próxima vez sigue donde se quedó.
4. Si sale «Sin conexión», pulsa **Buscar actualizaciones** para intentarlo otra vez.

En **Configuración** deja vacío el campo «Servidor de canciones» para usar el servidor oficial.
